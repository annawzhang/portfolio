四项日常工作

1 · 批次采集与质检

  • 按批次运行 GitHub / Hugging Face / Scholar 多源采集
  • 处理 API 配额耗尽、站点拦截等故障：切换备选接口或改走 DOI 批量拉取
  • 采集中断按断点续传恢复，避免重复采集
  • 同名主体消歧、错位校验，异常数据自动标记待人工复核

采集流水线设计 →

2 · 取数支持与漏斗监控

  • 用可复用 SQL 模板做增量计算，不必每次全量重算
  • 盯触达率、转化等核心指标的异动
  • 按分层、地域、赛道、时间窗口拆解，定位差异来源
  • 响应业务同学的临时取数需求

漏斗看板与 AB 实验 →

3 · 评分结果交付与校准

  • 把 S+/S/A/B/C 分层结果交付业务方使用
  • 收集跟进反馈，排查误判样本
  • 结合看板转化数据，反向微调维度权重

八维评估模型 →

4 · 协助梳理招聘 Agent：人才画像与招聘漏斗

  • 画像标签体系：经验年限、学历背景、技术栈、学术成果（顶会论文、专利、开源贡献、技术博客）和 AI 评分分档
  • 匹配规则：梳理技能、经验、文化、学历四类匹配维度，以及自动通过 / 推荐面试 / 自动淘汰三档阈值
  • 招聘漏斗：投递 → AI 初筛 → 初面 → 终面 → 入职的环节定义与转化口径，补充 Offer 审批节点
  • 与八维评估、漏斗看板的口径对齐，便于 Agent 直接复用
和项目的关系

项目负责搭能力（采集流水线、八维模型、关系网络模型、AB 实验体系）；日常工作负责让数据每批稳定产出、指标每天可查，把业务反馈带回模型迭代，并把画像和漏斗口径输出给招聘 Agent 使用。
