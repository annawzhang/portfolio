理想 · 销售策略：数据、AI 与舆情转化为一线工具讲稿

S 经营数据分散、门店口径不一；竞品信息主要依赖试驾录音，媒体舆情和用户讨论覆盖不足。

T 以日常销售运营为基本盘保障目标落地，同时用数据与 AI 提高分析效率，把洞察转化为一线用得上的策略与工具。

A 目标拆到城市部/门店/车型并分口径监控达成，每日操盘日报与海报宣发；建门店级经营驾驶舱和 AI 助手流水线（18 类产品/流程）；做 MEGA/ES9（437 条）、问界（6,841 条）舆情专项和外观话术手册；完成 17 城 50 门店竞品商圈匹配。

R 从"展示数字"走向"诊断 + 动作"；发现 54% 门店与问界同商圈；舆情洞察沉淀为六类场景销售话术。

腾讯 · Console 0→1 + Chatbot 知识闭环讲稿

S 海外业务工具分散，12 个专业 Agent 知识覆盖不足，未命中率高。

T Console 一站式工作台 + Gap Finder 驱动补库。

A 5 大板块聚合；21 书架/135 文献；问询 ETL + 聚类挖缺口；No-IOA 40min→3min。

R 未命中率 6%；Console 建库 → Chatbot 用库 → Gap Finder 补库。

字节 · AI 数据全链路 + 可解释评估模型讲稿

T Agent 驱动采集–清洗–交付；八维 V5.0 分层 + AB 实验。
